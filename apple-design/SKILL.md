# Apple Design

帮助界面及时响应、保持清晰层级，并让运动与操作连贯。这里是 Apple 官方资料的中文提炼和网页适配建议，不是官网全集，也不是 Apple 官方发布的 Skill。

## 核心判断

### 内容与操作

内容是主体，导航和控件帮助用户行动。用顺序、间距、对比和分组说明关系；不要用装饰、模糊或动效掩盖信息结构问题。

按下即给反馈，执行时机遵循控件语义：普通按钮通常在点击完成后提交动作，支持移开取消和键盘操作。即时反馈不意味着在 `pointerdown` 就执行付款、删除等业务动作。

### 连贯运动

拖拽跟随输入，保留抓取偏移；交接动画从当前显示状态开始。需要连续速度的交互用能够接收、保留速度的实现，改变目标时允许中断和重定向。

多数工具性动效先从克制、无明显过冲开始。惯性手势或有明确用途的操作提示可以使用适度弹性；不要把“无惯性”作为禁止弹性的绝对条件。

CSS transition 适合简单状态过渡，也支持中途反转；它不会自动解决手势跟随和物理速度连续性。按行为选择工具，不笼统禁止 CSS 动画。

### 材质与可读性

Liquid Glass 优先用于内容上方的关键导航和控件，避免把正文、列表、所有卡片都玻璃化。区分普通半透明材质与包含光学、适应性和形变行为的 Liquid Glass；`blur()` 本身不等于完整液态玻璃。

选材质先看情境与可读性。不要把“所有导航必须透明”“颜色必须放实色层”“大组件必须更黑”写成通用要求。玻璃着色保留材质感，只突出重要动作。

### 平台与无障碍

保留原生按钮、链接、输入控件的语义、可见焦点和键盘能力。支持文字放大，尊重减少动态效果、减少透明度与提高对比度的偏好；浏览器支持不足时保留清晰可用的回退。

参数、间距、模糊量与字距是项目起点，不是跨平台 Apple 固定规格。区分阻尼比与动画库的阻尼系数，区分网页字体行为与原生 Dynamic Type。

## 示例与验证

需要网页材质原型时，可复制 [独立 HTML 示例](assets/liquid-glass-demo.html)。它演示真实背景模糊、边缘高光、按压反馈及保留当前速度的弹簧选择状态；是网页近似，未实现背景折射或系统级光照。更高还原度按材质参考增加并验证光学效果。

验证改动对应的行为：移动与释放是否连贯、快速改变目标是否跳变、滚动背景下文字是否可读、键盘与触摸能否操作，以及必要的窄屏和无障碍回退。小改动不要求完整测试矩阵；原型不宣称达到系统级还原。

引用官方要求时给出对应页面；网页建议明确属于适配。资料冲突时优先采用适用平台的当前官方文档，课程案例和参数不能升级成普遍规则。官方资料核对日期：2026-10-02。
